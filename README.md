# 合作办学风险联动

本项目用于建设面向业务人员的纯服务端系统。代码按领域模型、应用服务、持久化与接口边界组织；时间、标识和外部输入应通过可替换端口接入，以便稳定复现状态变化。运行数据与本地配置不得写入源码目录。

30 余个合作项目同时推进时，单个签证、标准或师资问题会沿项目依赖影响多个招生批次。本服务登记项目依赖、风险事件、缓解措施与责任方，按**版本化规则**计算传播范围与处置时限，让管理部门看到风险传播全貌而非孤立告警。

## 架构

```
service_09252_007/
  domain/       领域模型：工作日历（跨地区）、版本化规则、严重级别
  app/          应用服务：RiskService，全部业务规则
  persistence/  持久化：SQLite 模式、连接与事务（BEGIN IMMEDIATE 串行化并发写）
  api/          接口边界：标准库 HTTP JSON API，仅做协议适配
  __main__.py   服务入口
```

时钟通过 `RiskService(db_path, clock=...)` 注入，测试用假时钟确定性复现。

## 领域概念

- **项目 / 依赖**：依赖边 `src -> dst` 表示 src 上的风险可传播到 dst；边有类型（visa / standard / faculty / campus …）。
- **风险事件**：以 `event_id` 为幂等键导入；同 id 重复导入是空操作，同 id 不同载荷报冲突。
- **基础风险 `B:<event_id>`** 与**派生风险 `D:<类别>:<项目>`**：派生风险按 （类别， 项目） 聚合，可拥有多条**独立依据**（不同源事件沿不同路径传来）。基础风险被**撤销**或**解决**后，只自动关闭不再有任何有效依据的派生风险；仍有独立依据的保持打开并按剩余依据重算级别与时限。
- **版本化规则**：传播边类型、逐跳衰减、最大深度、各级别处置工作日数都由规则集给出；规则按版本注册、不可变，每条风险固化计算时使用的规则版本，口径可回放。
- **处置时限**：按风险落点项目的**地区工作日历**以工作日计算（如 CN 周六日休+公共假期、GULF 周五六休），跨地区传播自然产生不同时限。
- **缓解措施与租约**：认领即获得带有效期的租约（`token` 为幂等键与操作凭证），过期可回收；完成/心跳/释放均需持有效租约。租约持久化于 SQLite，重启后仍有效。
- **豁免**：必须人工确认（`confirmed_by`）且带明确有效期 `[valid_from, valid_until)`；可按单条风险或 项目+类别 作用域豁免；到期或撤销后自动失效。
- **升级**：`esc_id` 幂等；生效级别取原始级别与所有升级目标的最大值，时限随之收紧；`sweep` 对逾期未决风险按固定幂等键逐级自动升级。
- **复盘**：仅对已关闭/已解决风险登记，每条风险一份。

## 一致性设计

- **重复消息**：事件、撤销、升级、措施、豁免、复盘均以客户端幂等键去重，重复投递不改变结果。
- **乱序消息**：撤销以事件标识为准而非到达顺序——撤销先到时记入 `pending_revocations`，事件补到后立即生效；两种顺序的最终状态完全一致（测试用全量状态快照验证）。传播聚合是按集合计算的，与事件到达顺序无关。
- **依赖环**：传播按路径截断（不重复访问项目），每项目保留最高残余级别，保证终止且不产生重复风险。
- **可恢复**：全部状态（含租约与审计流水）在 SQLite 中，进程重启后完整恢复。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/projects` | 登记项目（含地区） |
| POST | `/calendars` | 注册/覆盖地区工作日历 |
| POST | `/dependencies` | 登记依赖边 |
| POST | `/rules` · GET `/rules/active` | 注册规则版本 / 查当前版本 |
| POST | `/events/import` | 批量导入风险事件（逐条返回结果） |
| POST | `/events/{id}/revoke` | 撤销事件（乱序安全） |
| GET | `/events/{id}/impact` | 事件传播视图 |
| GET | `/projects/{id}/impact` | 项目风险视图 |
| GET | `/impact/summary` | 管理汇总（各项目计数/最高级别/最近时限） |
| GET | `/risks/{id}` | 风险详情（依据/措施/升级/豁免） |
| POST | `/risks/{id}/resolve` · `/escalate` | 解决 / 升级 |
| POST | `/risks/{id}/postmortems` · GET `/risks/{id}/postmortem` | 复盘 |
| POST | `/measures` · `/measures/{id}/claim` · `/heartbeat` · `/release` · `/complete` | 措施与认领 |
| POST | `/exemptions` · `/exemptions/{id}/revoke` | 豁免 |
| POST | `/maintenance/sweep` | 回收过期租约、逾期自动升级 |
| GET | `/audit` | 审计流水（可按 entity/entity_id 过滤） |

错误统一为 `{"error": {"code", "message", "details"}}`，HTTP 状态由错误类型决定（400/404/409/422）。
